# Priya Jha | Data Analyst Portfolio

A modern, responsive portfolio website showcasing my data analytics projects, skills, and experience. Built with React, Vite, and Tailwind CSS.

**Live site:** [priya-jha-portfolio.vercel.app](https://priya-jha-portfolio.vercel.app/)

---

## About

I'm Priya Jha, a Computer Science graduate (B.Sc) from Mumbai, looking for an entry-level Data Analyst role. This portfolio presents my work in SQL, Python, Excel, and Power BI, including my data analytics internship at ElevanceSkills and my hands-on projects.

## Features

- **Hero section** with an animated background, skills marquee, and a one-click resume download
- **About section** with my background and key strengths
- **Projects section** featuring data analytics projects, each linked to its GitHub repository
- **Experience timeline** covering my internship and project work
- **Contact form** that delivers messages straight to my inbox using EmailJS
- **Fully responsive** design for desktop, tablet, and mobile
- **Dark theme** with glassmorphism cards, smooth animations, and a teal accent color

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/PriyaJha-14/PRIYA.git
   cd PRIYA
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root (see [Environment Variables](#environment-variables))

4. Start the development server

   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser

### Build for production

```bash
npm run build
npm run preview
```
